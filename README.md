# Ciclo de vida de una IA responsable: reingreso hospitalario a 30 días

Notebook de referencia del reporte de la materia **Ética en IA** (Equipo 2).

`IA_Responsable_Reingreso_30_dias.ipynb` reproduce los resultados del reporte:

- Base de 100 pacientes sintéticos (50 con sesgo y 50 sin sesgo).
- Análisis de sesgos y matriz de correlación de Pearson.
- Agente basado en distancias con explicación e indicador de validez (semáforo de distancia).
- Prueba dejando uno fuera, prueba contrafactual de género y dos casos de uso.

Requisitos: Python 3, `numpy`, `pandas`, `matplotlib`.
